# Dad Joke Showdown

One original dad joke for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on make.fun: a father puts his money in the freezer so he can have cold, hard cash for dessert. The program writes the single joke to `entry.txt` — nothing else, no tricks, just the pun landing at the end.
